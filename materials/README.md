# 素材投放区

把要给我的资料放这个目录就行。**这个目录不会提交到 GitHub**（`.gitignore` 已排除），
老师的 PPT 不会出现在你的公开仓库里。

## 放什么

| 类型 | 支持的格式 | 我会怎么处理 |
| --- | --- | --- |
| 课堂 PPT | `.pptx`、`.pdf`、`.ppt`（另存为 pptx 更好） | 提取定义、例题、老师强调的点 → 补进 `knowledge/*.md` |
| 期末真题 / 模拟卷 | `.pdf`、`.docx`、图片 | 编程题 → `problems/*.json`（带测试数据，可直接判题）；选择填空 → 先记录，后面加题型 |
| 实验指导书 | `.docx`、`.pdf` | 对照它检查代码模板的函数名、参数顺序对不对 |
| 课堂笔记 / 截图 | 图片、`.md`、`.txt` | 直接读，整理成知识点 |

## 怎么命名（方便我对上章节）

```
第一章-绪论.pptx
第二章-线性表.pptx
第三章-栈和队列.pptx
2024秋-期末A卷.pdf
2024秋-期末A卷-答案.pdf
实验一-顺序表.docx
```

不按这个命名也能读，只是我得先猜是哪一章。

## 我处理完会做什么

1. 新内容写进 `backend/content/<章节>/`，不碰代码；
2. 跑 `scripts/verify.ps1`，确保新题的参考解能通过所有测试点；
3. 提交并推送到 GitHub，commit message 写清楚"补充了什么"。

## 小提示

- **有答案的卷子价值最高**：有标准答案我才能把测试数据写对。
- 卷子如果只有照片，尽量拍正、别截掉题干的数据范围——数据范围决定题目该考什么复杂度。
- 一次性发一整套也没问题，我按章节慢慢消化；也可以每次发一章，做完你再检查。
