## 循环单链表

把最后一个结点的 `next` 从 `NULL` 改成指向头结点，就成环了。

```
head → [头] → [d1|●] → [d2|●] → [d3|●] ┐
         ↑                              │
         └──────────────────────────────┘
```

**好处**：从任意一个结点出发都能走遍全表。

**判空条件**：`head->next == head`（不是 `== NULL` 了，这点经常考）。

**应用**：约瑟夫环。它天生就是"一圈人"的模型，用循环链表模拟最直观。

:::tip 尾指针的妙用
如果只设**尾指针 `rear`**（不设头指针），那么：

- 表尾是 `rear`；
- 表头是 `rear->next`；
- 在表头插入、在表尾插入都是 **O(1)**。

所以"需要在表头表尾都频繁操作"的场景（比如合并两个循环链表），用尾指针比头指针更方便。这是选择题的常客。
:::

## 双向链表

每个结点多一个 `prior` 指针，指向前驱。能"往回走"了。

```cpp
typedef struct DNode {
    int data;
    struct DNode *prior, *next;
} DNode, *DLinkList;
```

代价：每个结点多一个指针，存储密度更低；插入删除要改 **4 个指针**，顺序更讲究。

### 在 p 之后插入 s

```
    ┌── prior ──┐        ┌── prior ──┐
p ←─┘           └→ s ←───┘           └→ 原来的后继
```

四步，顺序**不能乱**：

```cpp
s->next = p->next;        // ① s 指向前驱 p 的后继
if (p->next != NULL)      // ② 如果 p 后面真有结点
    p->next->prior = s;   //    让它的 prior 指回 s
s->prior = p;             // ③ s 的 prior 指向 p
p->next = s;              // ④ p 的 next 指向 s（必须最后做）
```

口诀：**先管后面的两个指针，最后改 p->next**。因为 `p->next` 一旦改了，就再也找不到原来的后继，② 就没法做了。

### 删除 p 的后继 q

```cpp
q = p->next;
p->next = q->next;
if (q->next != NULL) q->next->prior = p;
delete q;
```

双向链表删除时**不用再找前驱**，这是它最大的价值——单链表删除某个结点必须先遍历找前驱，是 O(n)；双向链表如果已经拿到该结点的指针，删除就是 O(1)。

:::exam 对比记忆
| | 单链表 | 双向链表 | 循环单链表 |
| --- | --- | --- | --- |
| 找前驱 | O(n) | O(1) | O(n) |
| 删除已知结点 | O(n)（要找前驱） | O(1) | O(n) |
| 判空 | `L->next == NULL` | `L->next == NULL` | `L->next == L` |
| 多出的指针 | 无 | 1 个 prior | 无 |
:::

## 静态链表（了解即可）

用**数组**模拟链表：每个元素存 `data` 和 `next`（存的是**下标**而不是地址）。

```cpp
typedef struct {
    int data;
    int next;   // 下一个元素在数组里的下标，-1 表示结束
} SLinkList[MAXSIZE];
```

适用于不支持指针的语言，或者考试里让你"用数组实现链表"。重点只有一个：**`next` 存的是数组下标**，考选择题时别被绕进去。
