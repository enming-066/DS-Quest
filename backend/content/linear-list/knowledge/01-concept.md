## 先用人话说

想象一排存包柜，编号 1、2、3……每个柜子里放一样东西，**除了第一个，每个柜子前面都有一个柜子；除了最后一个，每个柜子后面都有一个柜子**。这就叫"线性"。

线性表就是这样一个有限序列：`(a1, a2, a3, …, an)`

- `n` 是表长，`n = 0` 时叫**空表**。
- `a1` 是**首元**（表头元素），`an` 是**尾元**。
- `ai` 的前一个叫**直接前驱** `a(i-1)`，后一个叫**直接后继** `a(i+1)`。
- 元素之间只有"前后"关系，没有"左右""上下"关系——这就是线性结构。

:::warning 注意
线性表里的元素**类型相同**、**个数有限**、**有顺序**。少了任何一条都不是线性表。
比如"一个班所有同学的姓名"是；"这学期所有课程的先修关系"就不是（那是一张图）。
:::

## 两组容易混的概念

这是第一章最爱出的送分题，也是最爱丢分的题。

| 对比项 | 逻辑结构 | 存储结构 |
| --- | --- | --- |
| 回答的问题 | 元素之间**是什么关系** | 数据在**内存里怎么摆** |
| 与语言有关吗 | 无关，是抽象模型 | 有关，要落到具体语言和内存 |
| 线性表的例子 | 线性结构（一对一） | 顺序存储、链式存储 |
| 其他例子 | 树形结构、图形结构、集合 | 索引存储、散列存储 |

一句话记忆：**逻辑结构说的是"关系"，存储结构说的是"摆放"。** 线性表是逻辑结构，顺序表和链表是它的两种存储实现。

## 抽象数据类型 ADT

课件第 1 章 P10 给出的 ADT 是这样的（注意它和后面代码里的函数名一一对应）：

```
抽象数据类型 LinearList {
    实例（数据 D 和关系 S）
        0 个或多个元素的有序集合
    操作
        create()     创建一个空线性表
        destroy()    删除表
        empty()      表空返回 true，否则 false
        size()       返回表中元素个数
        get(k)       返回下标为 k 的元素
        indexOf(x)   返回 x 在表中的下标，不在表中返回 -1
        delete(k)    删除下标为 k 的元素，其后元素下标减 1
        insert(k,x)  把 x 插入到下标 k 的位置，其后元素下标加 1
        output()     从起始位置到终止位置输出元素
}
```

课件特别注明：**ADT 可以根据实际应用自行定义**。所以考试里看到 `InitList`、`ListInsert` 这类名字也别慌——那是另一本教材（严蔚敏版）的命名，语义和这里的 create/insert 一样。

:::exam 常见考法
考试里问"线性表的基本操作有哪些"，答出**建表、判空、求长、取值、查找、插入、删除、遍历**就够拿分。
注意术语要和课件对齐：课件用 `get(k)` / `indexOf(x)` / `insert(k,x)` / `erase(k)`，而严蔚敏教材用 `GetElem` / `LocateElem` / `ListInsert` / `ListDelete`。两种写法指的是同一组操作。
:::

## 位序 vs 数组下标（提前预警）

这是初学者第一个大坑，后面顺序表那一节还会反复出现：

| 说法 | 取值 | 例子 |
| --- | --- | --- |
| **位序**（第几个） | 从 **1** 开始 | 第 1 个元素是 `a_1` |
| **下标**（数组） | 从 **0** 开始 | `a[0]` 才是第一个元素 |

所以"在第 i 个位置插入"对应数组下标 `i-1`，"删除第 i 个元素"也是下标 `i-1`。每年都有人在这里差一。

## 两种存储方式，先有个印象

| | 顺序存储（顺序表） | 链式存储（链表） |
| --- | --- | --- |
| 内存 | 一块连续空间 | 一堆分散的结点，靠指针相连 |
| 找第 i 个 | 一步到位 O(1) | 从头走 i 步 O(n) |
| 插入/删除 | 平均要挪一半元素 O(n) | 改指针 O(1)（前提是已找到位置） |
| 额外开销 | 无 | 每个结点多一个指针 |
| 适合 | 查得多、改得少 | 改得多、查得少 |

这一关剩下的内容，就是把这张表吃透。
