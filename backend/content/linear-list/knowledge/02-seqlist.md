## 一句话理解

顺序表 = **数组 + 一个记录当前长度的变量**。因为内存连续，所以能"一步算地址"，也正因为连续，插入删除时必须给新元素腾位置或把空洞补上。

地址计算公式（考试常考）：

```
LOC(a_i) = LOC(a_1) + (i - 1) * sizeof(ElemType)
```

## 结构定义：静态 vs 动态

**静态分配**：数组大小写死，简单但容易溢出。

```cpp
#define MAXSIZE 100
typedef struct {
    int data[MAXSIZE];   // 静态数组
    int length;          // 当前长度
} SqList;
```

**动态分配**：用 `new`/`malloc` 按需申请，可以扩容。

```cpp
typedef struct {
    int *data;
    int length;
    int capacity;
} SqList;
```

:::tip 考试写法
课本上的 `SqList` 通常就是"数组 + length"两行。做题时手写结构体，把 `length` 记得初始化成 0，这是最常被扣分的地方。
:::

## 插入：为什么是从后往前挪

要在第 `i` 个位置（位序，从 1 开始）插入 `e`，原来 `a_i … a_n` 都要往后挪一格。

```
下标:   0    1    2    3    4
原来:  [10] [20] [30] [40] [50]     length = 5
在第 3 个位置插入 99（下标 2）
↓ 从最后往前挪
      [10] [20] [  ] [30] [40] [50]
↓ 放入 99
      [10] [20] [99] [30] [40] [50]  length = 6
```

**必须从后往前挪**。如果从前往后挪，`data[2]` 会先被覆盖成 `data[1]` 的值，后面全乱。这是笔试最爱考的细节。

```cpp
// 在第 i 个位置（位序，1 <= i <= length+1）插入 e
bool ListInsert(SqList &L, int i, int e) {
    if (i < 1 || i > L.length + 1) return false;   // 位置非法
    if (L.length >= MAXSIZE) return false;          // 满了
    for (int j = L.length; j >= i; j--) {           // 从后往前
        L.data[j] = L.data[j - 1];
    }
    L.data[i - 1] = e;                              // 位序 i → 下标 i-1
    L.length++;
    return true;
}
```

### 插入的时间复杂度

在长度为 `n` 的表里，"在第 i 个位置插入"要移动 `n - i + 1` 个元素。

假设每个位置插入的概率相等（都是 `1/(n+1)`），平均移动次数：

```
E = (1/(n+1)) * Σ(n - i + 1)  (i = 1..n+1)
  = (1/(n+1)) * (n + (n-1) + ... + 1 + 0)
  = (1/(n+1)) * n(n+1)/2
  = n/2
```

**结论：平均移动 n/2 个元素，时间复杂度 O(n)。** 在表尾插入不用移动，是 O(1)。

## 删除：为什么是从前往后挪

删除第 `i` 个元素后，后面的元素要往前补一格。

```
原来:  [10] [20] [99] [30] [40]   删除第 3 个（下标 2）
↓ 从前往后挪
      [10] [20] [30] [40]         length 减 1
```

```cpp
// 删除第 i 个元素，用 e 返回被删的值
bool ListDelete(SqList &L, int i, int &e) {
    if (i < 1 || i > L.length) return false;
    e = L.data[i - 1];
    for (int j = i; j < L.length; j++) {   // 从前往后
        L.data[j - 1] = L.data[j];
    }
    L.length--;
    return true;
}
```

删除第 `i` 个元素要移动 `n - i` 个元素，平均移动 `(n-1)/2` 个，**时间复杂度仍是 O(n)**。删除表尾是 O(1)。

:::exam 高频结论表
| 操作 | 最好 | 最坏 | 平均 | 关键点 |
| --- | --- | --- | --- | --- |
| 按位查找 `GetElem` | O(1) | O(1) | O(1) | 下标直接算 |
| 按值查找 | O(1) | O(n) | O(n) | 只能顺序扫 |
| 插入 | O(1)（表尾） | O(n)（表头） | O(n)，平均挪 n/2 | 从后往前 |
| 删除 | O(1)（表尾） | O(n)（表头） | O(n)，平均挪 (n-1)/2 | 从前往后 |

考试爱问："在长度为 n 的顺序表中插入一个元素，平均要移动多少个元素？" 答 **n/2**。"删除呢？" 答 **(n-1)/2**。这两个数一定要记住。
:::

## 一个容易错的地方：判断条件

```cpp
if (i < 1 || i > L.length + 1) return false;  // 插入：可以插到 length+1（表尾之后）
if (i < 1 || i > L.length)     return false;  // 删除：最多删到 length
```

插入的合法范围比删除多一个 `length + 1`，因为"插在最后一个元素后面"是合法的。这个 `+1` 是选择题常客。

## 顺序表的优缺点

**优点**

- 支持**随机访问**，`GetElem` 是 O(1)，这是链表永远比不了的。
- 存储密度高，不需要额外指针。
- 代码简单，缓存友好（连续内存，CPU 预取快）。

**缺点**

- 插入删除要移动大量元素，O(n)。
- 需要预先知道大致规模；动态扩容要整体复制，代价高。
- 容易产生"碎片"：一个很大的表可能因为找不到连续空间而失败。

:::pitfall 新手常见错误
1. `for (int j = L.length; j >= i; j--)` 写成 `j > i`，少挪一个，结果覆盖了原数据。
2. 插入后忘记 `L.length++`，删除后忘记 `L.length--`。
3. 位序当成了下标，`L.data[i]` 应为 `L.data[i-1]`。
4. `length` 没初始化。局部变量是随机值，一定要写 `L.length = 0`。
:::
