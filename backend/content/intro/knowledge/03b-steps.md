## 为什么要数"步"

光看循环嵌套层数，有时判断不了谁快谁慢。课件给了一个更精确的办法：**给每条语句规定一个 s/e（steps per execution，每次执行的步数），乘上它执行的次数，加起来就是总步数。**

总步数是**具体数字**（比如 `2n+3`），再对它取阶，就得到渐进复杂度（`Θ(n)`）。

## 例 1：一维数组求和

```cpp
template<class T>
T Sum(T a[], int n) {
    T tsum = 0;                     // 1 步
    for (int i = 0; i < n; i++)     // 循环头，判断 n+1 次
        tsum += a[i];               // 循环体，执行 n 次
    return tsum;                    // 1 步
}
```

| 语句 | s/e | 频率 | 总步数 |
| --- | --- | --- | --- |
| `tsum = 0;` | 1 | 1 | 1 |
| `for (i = 0; i < n; i++)` | 1 | n + 1 | n + 1 |
| `tsum += a[i];` | 1 | n | n |
| `return tsum;` | 1 | 1 | 1 |
| **合计** | | | **2n + 3** |

所以 `Sum` 的执行步数是 `2n+3`，渐进复杂度 `Θ(n)`。

:::tip 为什么循环头算 n+1 次
`i < n` 这个判断，在 `i = 0,1,…,n-1` 时都为真（n 次），当 `i = n` 时还要判断一次才退出，所以是 **n+1 次**。
这个"+1"是填空题最常丢分的地方。
:::

## 例 2：递归求和

```cpp
template<class T>
T Rsum(T a[], int n) {
    if (n > 0) return Rsum(a, n - 1) + a[n - 1];   // 2 步
    return 0;                                       // 1 步
}
```

设 `t(n)` 为执行步数，则：

```
t(0) = 1
t(n) = 2 + t(n-1)      (n > 0)
```

展开：`t(n) = 2n + 1`。递归和迭代的渐进复杂度都是 `Θ(n)`，但递归每次多一次函数调用（压栈/出栈），**实际常数更大**。

## 例 3：二维数组转置

```cpp
for (int i = 0; i < rows; i++)          // rows + 1 次
    for (int j = 0; j < cols; j++)      // rows × (cols + 1) 次
        b[j][i] = a[i][j];              // rows × cols 次
```

| 语句 | s/e | 频率 | 总步数 |
| --- | --- | --- | --- |
| 外层循环头 | 1 | rows + 1 | rows + 1 |
| 内层循环头 | 1 | rows × (cols + 1) | rc + r |
| 赋值语句 | 1 | rows × cols | rc |
| **合计** | | | **2rc + 2r + 1** |

取阶：`Θ(rc)`。注意不是 `Θ(r+c)`——这是初学者最容易写错的地方。

## 执行步数和渐进复杂度的关系

| | 执行步数 | 渐进复杂度 |
| --- | --- | --- |
| 含义 | 具体的操作次数 | 增长趋势的阶 |
| 依赖 | 语句的 s/e 约定、编译器、输入 | 只依赖 n |
| 用途 | 比较**同一台机器、同一份代码**的常数差异 | 判断规模变大后谁能扛住 |

**结论：执行步数用来比较"常数"，渐进复杂度用来比较"增长"。** 考试两种都可能问。

## 操作计数（operation count）与执行步数的区别

- **操作计数**：只数"关键操作"（比如排序里的比较次数、矩阵乘法里的乘法次数）。
- **执行步数**：数所有语句的步数总和。

课件的例子：多项式求值的"鲁莽算法"要 `2n` 次乘法，Horner 算法只要 `n` 次——**比较的是操作计数**，不是执行步数。

:::exam 一句话
问"比较次数"→ 数比较；问"执行步数"→ 按 s/e 表加；问"时间复杂度"→ 取阶。
:::

:::pitfall 三个易错点
1. 循环头忘算 +1 次（`i < n` 的最后一次判断）。
2. 内层循环的总次数写成 `cols+1` 而忘了乘外层 `rows`。
3. 把 `2rc + 2r + 1` 的阶写成 `Θ(r+c)`。
:::
