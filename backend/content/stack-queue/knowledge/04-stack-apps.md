## 应用一：括号匹配

给一串括号，判断是否配对。规则：

- 遇到左括号 → 压栈；
- 遇到右括号 → 看栈顶是不是对应的左括号，是就弹出，不是就不匹配；
- 扫完后栈必须为空。

```cpp
bool Match(const string &s) {
    stack<char> st;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') {
            st.push(c);
        } else if (c == ')' || c == ']' || c == '}') {
            if (st.empty()) return false;          // 右括号多了
            char t = st.top();
            if ((c == ')' && t != '(') ||
                (c == ']' && t != '[') ||
                (c == '}' && t != '{')) return false;   // 类型不配对
            st.pop();
        }
    }
    return st.empty();                             // 左括号多了也不匹配
}
```

**三种失败情况**：右括号多余、类型不匹配、左括号多余。三个都要考虑到，漏一个就是 WA。

## 应用二：出栈序列合法性（超高频考点）

给入栈顺序 `1, 2, 3, ..., n`，再给一个出栈序列，问是否可能。

**判定方法**：用一个栈模拟。

- 按 `1..n` 依次入栈；
- 每入栈一个，就检查栈顶是否等于出栈序列的当前元素，能弹就一直弹；
- 最后栈空且序列走完 → 合法。

```cpp
bool Valid(int n, int out[]) {
    stack<int> st;
    int j = 0;                          // 出栈序列的下标
    for (int i = 1; i <= n; i++) {
        st.push(i);
        while (!st.empty() && st.top() == out[j]) {
            st.pop();
            j++;
        }
    }
    return st.empty() && j == n;
}
```

:::exam 记忆口诀
**"入栈一个，能弹就弹"**。只要最后栈空，序列就合法。

最常见的错误答案：`3 1 2`。因为 3 出栈时 1、2 已经在栈里，且 2 在 1 上面，所以 1 不可能比 2 先出。
经典结论：**对于 `1..n` 的入栈顺序，若出栈序列中出现了 `i < j < k` 且出栈顺序是 `k, i, j`，则不合法**（"大数先出，则小的必须逆序"）。
:::

### 合法出栈序列的个数

这是卡特兰数（Catalan number）：

```
C(n) = (1/(n+1)) * C(2n, n)

n=1: 1
n=2: 2      (12, 21)
n=3: 5      (123,132,213,231,321)
n=4: 14
n=5: 42
```

考试问"n 个元素依次入栈，可能的出栈序列有多少种"，答卡特兰数。1、2、5、14、42 这几个数背下来。

## 应用三：表达式求值

考试一般考**后缀表达式（逆波兰式）求值**，因为它不需要处理优先级，最适合用栈。

规则：从左到右扫，遇到数字压栈，遇到运算符就弹出两个数计算，结果再压回去。

```cpp
int EvalPostfix(const vector<string> &tokens) {
    stack<int> st;
    for (const string &t : tokens) {
        if (t == "+" || t == "-" || t == "*" || t == "/") {
            int b = st.top(); st.pop();     // 先弹出的是右操作数！
            int a = st.top(); st.pop();
            if (t == "+") st.push(a + b);
            else if (t == "-") st.push(a - b);
            else if (t == "*") st.push(a * b);
            else st.push(a / b);
        } else {
            st.push(stoi(t));
        }
    }
    return st.top();
}
```

:::pitfall 最容易错的地方
`a - b` 和 `a / b` 是有顺序的！先弹出的是**右操作数**，后弹出的才是左操作数。写成 `st.push(b - a)` 就全反了。

例：后缀 `5 3 -`，先弹 3（右），再弹 5（左），结果是 `5 - 3 = 2`。
:::

### 中缀转后缀（了解思路）

用栈暂存运算符：

1. 数字直接输出；
2. 左括号入栈；
3. 右括号：不断弹出并输出，直到遇到左括号（左括号弹出但不输出）；
4. 运算符：弹出所有**优先级 ≥ 自己**的运算符并输出，然后自己入栈；
5. 扫完后把栈里剩下的全部输出。

例：`a+b*c` → `a b c * +`；`(a+b)*c` → `a b + c *`。

## 应用四：递归与栈

递归函数执行时，系统用**函数调用栈**保存每一层的参数和返回地址。所以"递归能做的事，用栈 + 循环也能做"。

经典例子：斐波那契、汉诺塔、树的遍历。考试常问"递归的优点/缺点"：

- 优点：代码简洁，符合数学定义。
- 缺点：每次调用都要压栈，空间开销大；递归太深会**栈溢出**；重复计算多（斐波那契不用记忆化就是指数级）。

:::tip 什么时候该用栈代替递归
当递归深度可能达到 10^6 时（比如深链表的遍历、大迷宫 DFS），递归必然爆栈，必须改成显式栈 + 循环。这是很多 OJ 上"递归超内存"的真正原因。
:::
