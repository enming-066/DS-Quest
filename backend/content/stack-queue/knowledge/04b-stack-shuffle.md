## 什么是栈混洗

给定固定输入序列（比如 `1, 2, 3, 4`），通过一系列合法的入栈（Push）和出栈（Pop）操作，能得到的不同输出序列，每个都叫一个**栈混洗（stack permutation）**。

例如输入 `1 2 3`，合法的输出有 5 种：`123、132、213、231、321`，而 `312` 不可能。

## 用 S / X 表示操作序列

- **S** = 入栈（push）
- **X** = 出栈（pop）

n 个元素的操作序列里，必然有 **n 个 S 和 n 个 X**。

**合法的条件**：任意前缀中，S 的个数 ≥ X 的个数。（否则就会"从空栈里弹出元素"。）

```
输入 1 2 3，输出 3 2 1：
S S S X X X        ✓ 每个前缀 S 都不少于 X

输入 1 2 3，想得到 3 1 2：
要 3 先出栈 → S S S X（此时栈里是 1 2）
接下来只能出 2，不可能出 1 → 非法
```

:::exam 一句话判定法
**大数先出栈，比它小的数只能按逆序出。**
看到 `3 1 2`：3 先出，剩下的 2 在 1 上面，所以必须 `2` 先于 `1`——`1 2` 是正序，非法。
:::

## 通用判定算法（模拟）

```cpp
bool valid(int n, int target[]) {       // 入栈顺序 1..n
    int st[100005], top = -1, j = 0;
    for (int i = 1; i <= n; i++) {
        st[++top] = i;                                  // 入栈
        while (top >= 0 && st[top] == target[j]) {      // 能弹就弹
            top--;
            j++;
        }
    }
    return top < 0 && j == n;
}
```

思路：**按入栈顺序一个个压，每压一个就看栈顶是不是目标序列的当前元素，是就一直弹。**
最后栈空且序列走完，就合法。

时间复杂度 `Θ(n)`，因为每个元素最多入栈一次、出栈一次。

## 合法序列的个数：卡特兰数

n 个元素的合法栈混洗个数，恰好是第 n 个**卡特兰数**：

```
C(n) = C(2n, n) / (n + 1)
```

| n | 1 | 2 | 3 | 4 | 5 | 6 | 10 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| C(n) | 1 | 2 | 5 | 14 | 42 | 132 | 16796 |

:::exam 为什么是卡特兰数
把 S 看成"左括号"、X 看成"右括号"，"任意前缀中 S 不少于 X"就等价于"括号序列合法"。
而 n 对括号的合法序列数正是卡特兰数——这就是两个问题同构的原因。
:::

### 卡特兰数的其他应用（课件列了 4 个）

| 场景 | 为什么同构 |
| --- | --- |
| n 对括号的合法组合 | 左括号=入栈，右括号=出栈 |
| n 个结点的不同二叉搜索树形态数 | 左右子树规模之和 = n-1 |
| n+2 边形三角划分方案数 | 每次划分对应一次"配对" |
| n×n 网格不越对角线的路径数 | 向右=入栈，向上=出栈 |

## 与"括号匹配"的关系

两者是同一个模型：**括号匹配是判定单个序列是否合法，栈混洗是所有合法序列的集合。**

所以括号匹配的代码可以直接拿来改：把"左括号入栈、右括号比对栈顶"换成"下一个输入元素入栈、目标元素比对栈顶"。

## 复杂度对比

| 方法 | 时间 | 说明 |
| --- | --- | --- |
| 直接模拟判定 | `Θ(n)` | 每个元素进出各一次 |
| 枚举所有序列再判定 | `Θ(n · C(n))` | n 大时爆炸，不可取 |
| 用卡特兰公式直接算个数 | `Θ(n)`（用递推）或 `Θ(1)`（用公式 + 大数） | 只求个数时用 |

:::pitfall 三个易错点
1. 把"合法"理解成"能出栈"，忽略了"栈不能为空时才能出"。
2. 判定时只检查了弹出，忘了最后栈必须为空。
3. 卡特兰数算成 `C(2n,n)`，忘了除以 `n+1`。
:::
